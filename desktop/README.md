# NOCTRA Windows 1.4.0

No Windows, execute `npm install` e `npm run dist` nesta pasta. O instalador sai em `dist/`. A interface é copiada de `../NOCTRA-codigo`, para manter a versão web e desktop sincronizadas.

A primeira abertura importa as músicas, playlists e favoritos da biblioteca nativa antiga para o armazenamento local da nova interface. Os arquivos originais e o library.json são preservados. A bandeja e os atalhos de mídia continuam disponíveis.
