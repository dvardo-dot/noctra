# NOCTRA 1.4.0

Player musical com três perfis independentes.

- Nightcore: desktop Windows 7 e coleção original.
- +: toca-discos com gestos e quatro wallpapers exclusivos.
- −: biblioteca de vidro translúcido, álbuns e sete wallpapers exclusivos.

O site está em `NOCTRA-codigo/`. Rode `npm start` nessa pasta para abrir a versão local. Músicas, capas, playlists e favoritos são guardados no navegador de cada perfil.

Produção Vercel: https://noctra-alpha.vercel.app

A versão Windows usa a mesma interface, com bandeja, atalhos de mídia e importação da biblioteca das versões anteriores.
