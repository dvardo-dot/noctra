# NOCTRA 1.4.0

Abra com `npm start` e acesse http://127.0.0.1:5500.

Três perfis independentes: Nightcore, + e −. Importe suas capas e MP3 pelo botão Importar. No +, arraste o vinil ou a agulha para buscar na música. No −, selecione uma capa para abrir o álbum. As galerias de wallpapers são próprias de cada perfil. Winamp, favoritos, playlists e exclusão da biblioteca estão disponíveis.

Os arquivos originais do computador não são movidos. O armazenamento local do navegador não é compartilhado entre domínios diferentes.
